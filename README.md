# 🐍 Snake Game - 贪吃蛇

一个色彩明亮、界面优美的经典贪吃蛇网页游戏，使用纯 HTML5 + CSS3 + JavaScript 构建。

## ✨ 功能特性

- **三种游戏模式** — 经典模式（碰墙即死）、无尽模式（穿墙+速度递增）、闯关模式（逐关挑战+加速）
- **穿墙机制** — 无尽/闯关模式下可从屏幕边缘穿越到对侧，附带光效和音效
- **WASD 键盘控制** — 使用 W/A/S/D 控制蛇的移动方向
- **空格加速** — 按住空格键可让蛇加速移动
- **最高分记录** — 按模式分别保存最高分到浏览器本地存储
- **游戏时长统计** — 实时显示当前游戏进行时间
- **8-bit 背景音乐** — 使用 Web Audio API 合成的经典贪吃蛇风格音乐，带贝斯伴奏
- **丰富音效反馈** — 吃食物、穿墙、升级、加速、游戏结束各有专属音效
- **闯关进度环** — 闯关模式下食物周围显示金色进度环和关卡进度
- **升级动画** — 闯关通关时全屏 LEVEL UP 动画特效
- **毛玻璃弹窗** — 开始和结束弹窗使用毛玻璃效果，带有平滑动画过渡
- **动态粒子背景** — 浮动粒子营造沉浸式视觉体验
- **发光渐变色蛇身** — 蛇身从翠绿渐变到蓝紫色，带有发光效果
- **脉冲食物** — 食物带有呼吸脉冲动画
- **响应式设计** — 适配桌面和移动端屏幕

## 🎮 操作说明

| 按键 | 功能 |
|------|------|
| <kbd>W</kbd> | 向上移动 |
| <kbd>S</kbd> | 向下移动 |
| <kbd>A</kbd> | 向左移动 |
| <kbd>D</kbd> | 向右移动 |
| <kbd>Space</kbd> | 按住加速 |

### 模式说明

| 模式 | 图标 | 玩法特点 |
|------|------|----------|
| 经典 | 🎯 | 碰墙即死，原汁原味 |
| 无尽 | ♾️ | 可穿墙，每吃 5 个食物加速一次 |
| 闯关 | 🏆 | 可穿墙，每关需吃目标数量食物后晋级，逐关加速 |

游戏规则：
- 控制蛇吃掉红色食物来增加长度和分数
- 撞到自己的身体则游戏结束（全模式）
- 经典模式下撞墙也会结束
- 尽可能获得更高的分数！

## 🚀 在线体验

直接打开 `index.html` 文件即可在浏览器中运行，无需安装任何依赖。

## 🛠️ 技术栈

- **HTML5** — 页面结构
- **CSS3** — 样式、动画、毛玻璃效果、响应式布局
- **JavaScript (ES6+)** — 游戏逻辑、Canvas 渲染
- **Web Audio API** — 8-bit 风格音乐和音效合成
- **Canvas 2D API** — 游戏画面渲染
- **localStorage** — 最高分本地持久化
